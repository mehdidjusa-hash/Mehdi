# سامانه آزمایشی Paper Trading بورس ایران

این پروژه فقط **تحلیل و معامله فرضی** انجام می‌دهد و به هیچ کارگزاری، حساب معاملاتی یا endpoint نوشتنی متصل نمی‌شود. سرمایه اولیه فرضی ۵۰٬۰۰۰٬۰۰۰ ریال است؛ مقدار را می‌توان در `config.json` تغییر داد.

## اجزای تیم

- `DataAgent`: دریافت snapshot بازار از TSETMC/webgw و ثبت زمان، منبع و وضعیت داده.
- `TechnicalAgent`: امتیازدهی روند، مومنتوم، حجم و فاصله از سقف/کف روز.
- `SwingAgent`: عامل مستقل نوسان‌گیری با قواعد محافظه‌کارانه، افق ۱ تا ۵ روز و حد ضرر مدل‌شده.
- `ScenarioLearningAgent`: ارزیابی هم‌زمان سناریوهای مومنتوم، بازگشت به میانگین، شکست و نقدشوندگی.
- `RiskAgent`: اندازه موقعیت، سقف ریسک هر معامله، سقف زیان روزانه و نقدشوندگی.
- `SupervisorAgent`: ادغام سیگنال‌ها و ردکردن نمادهای کم‌نقدشونده و سیگنال‌های کم‌اعتماد.
- `PaperBroker`: شبیه‌سازی پرشدن سفارش، کارمزد، لغزش، حد ضرر و هدف؛ بدون ارسال سفارش واقعی.

## حالت خودآموز

عامل خودآموز از هر معامله فرضی بسته‌شده، بازده سناریوی استفاده‌شده را ثبت می‌کند و وزن آن سناریو را با EWMA محدود به‌روزرسانی می‌کند. چهار سناریو همیشه ارزیابی می‌شوند و تصمیم فقط به یک مدل وابسته نیست. وزن‌ها بین `0.15` و `2.0` محدود هستند تا یک معامله خوش‌شانس یا بدشانس کل سامانه را منحرف نکند.

این یادگیری آنلاین، خودکار و قابل‌ردگیری است، اما یادگیری عمیق یا تضمین سود نیست. برای جلوگیری از بیش‌برازش باید نتایج در بازه‌های خارج از نمونه و در چند رژیم بازار بررسی شوند.

## اجرا

```bash
cd iran-paper-trader
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python3 paper_trader.py --once
```

برای پایش دوره‌ای:

```bash
python3 paper_trader.py --poll-seconds 60
```

پیش از استفاده، `config.json` را بررسی کنید. خروجی‌ها در `data/` و `reports/` نوشته می‌شوند.

## تست ایزوله

```bash
python3 -m venv /tmp/iran-paper-trader-venv
. /tmp/iran-paper-trader-venv/bin/activate
pip install -r requirements.txt pytest
pytest -q test_paper_trader.py test_learning_agent.py
python3 paper_trader.py --once --fixture test_fixture.json --db /tmp/paper-test.db
```

`test_fixture.json` فقط fixture کنترل‌شده برای بررسی منطق نرم‌افزار است و نباید به‌عنوان داده بازار یا نتیجه سرمایه‌گذاری استفاده شود.

## قواعد مهم آزمایش

- هیچ سفارش واقعی ساخته، ارسال، لغو یا اصلاح نمی‌شود.
- قیمت پرشدن فرضی برابر قیمت قابل‌معامله snapshot به‌علاوه لغزش محافظه‌کارانه است.
- کارمزد و حداقل اندازه موقعیت در محاسبات لحاظ می‌شوند.
- در صورت قطع منبع یا نامعتبر بودن پاسخ، سیگنال جدید صادر نمی‌شود؛ timestamp محلی هر snapshot ثبت می‌شود.
- نتیجه یک هفته برای اعتبارسنجی قطعی استراتژی کافی نیست؛ حداقل چند هفته و آزمون خارج از نمونه لازم است.
- «کمترین ضرر» یا «بهترین سهم» تضمین‌شدنی نیست. این ابزار پژوهشی است، نه توصیه قطعی سرمایه‌گذاری.
